# The Abnormal Library

A sample landing page for Abnormal Design Studio. Objects on a hand-drawn shelf are the site navigation; each one opens a "library card" section.

Open `index.html` in a browser, or serve the folder with any static server (e.g. `python3 -m http.server`).

Object art in `art/` is placeholder [OpenMoji](https://openmoji.org) line art (CC BY-SA 4.0, see `art/OPENMOJI-LICENSE.txt`) until the studio's own illustrations replace it.
